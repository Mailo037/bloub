Voice engine (Gemini)

Separate Sprach-Engine — unabhaengig von deinem Chat-Provider. Gemini liefert Sprache-zu-Text (Mikro) und Text-zu-Sprache (Antworten).

Speech-to-text and text-to-speech always use Google's matching models automatically (TTS: gemini-3.1-flash-tts, STT: gemini-3.6-flash). The model below is only stored for a future realtime (Live) session and is not used by the test or read-aloud buttons.

Voice replies

After a chat reply, Bloub reads it aloud with Gemini's text-to-speech (if voice replies are enabled).

Hold the hotkey to talk to Bloub — the input bar turns into a microphone while held. You can also click the microphone to start/stop (click again to mute & send). The hotkey applies immediately, no restart needed.

Get a Gemini API key

Free tier: Gemini TTS and Live currently have a rate-limited free tier. With free-tier keys, submitted data may be used to improve Google's products. Paid projects have higher limits and their data is not used for that purpose.

  1. Open and sign in with a Google account.
  2. Open the and check the free tier limits for the model you picked.
  3. In AI Studio → Get API key → Create API key — copy the key.
  4. Paste it above and press Test connection.

The free tier is currently available in the EU / EEA, UK and Switzerland too. Your actual model quota is shown in Google AI Studio and can change over time.

Startup

Launch Bloub Pet automatically whenever the PC starts (login item).

Life

Idle animations while nobody is poking it.

Autopilot

Periodically wakes the bloub and lets the AI decide on its own whether it wants to do something. The AI knows the user never asked. "Visible" shows its reply in the chat, "Silent" only shows actions — never text.

Actions

Persistent memory: remembers stable facts about you across chat sessions via memory_write/memory_get. Stored locally in your user data folder.

Caps how many tools the bloub may call while working on one message (and how often it may draw). When a budget is hit, it just answers in text instead.

File access

Global filesystem capability for granted folders. Read = list/read/search; read & write additionally allows creating and editing files. "None" disables all filesystem tools.

Terminal

Allow the bloub to run terminal commands on your machine. Powerful — only enable if you trust it. Commands run with a 30s timeout and output is capped.

Screens & vision

When the AI takes a screenshot, capture ALL connected monitors and stitch them into one image arranged by their real position. Each monitor region gets a small numbered badge (1, 2, …) in its top-left corner so the AI can tell the screens apart. Off = only the monitor next to the pet.

Let the bloub watch your cursor across every monitor (with a tiny display-ID tag), not just inside its own window.

Full drive access

Grant the bloub full read (and write if enabled) access to your system drive (C:\). This adds a permanent grant for the root drive so the AI can inspect files anywhere without needing to drop a folder first.

Leave

Activity recall

When enabled, Bloub keeps a local record of what you do on this PC: terminal commands you execute, which apps you focus, and (optionally) web posts you send. Everything stays in this user-data folder — nothing is uploaded and the AI only sees it through bounded search tools. Recording is OFF until you turn it on.

Recording

Hotkey Ctrl+Alt+P pauses/resumes instantly. Recording also auto-pauses while a password or banking window is focused.

Terminal capture

Records commands AFTER you run them — never the keystrokes while typing. Needs a small hook in your PowerShell profile (installed below).
