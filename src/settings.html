Live voice chat

Gemini uses the key from Connections. The OpenAI key is also used for OpenAI transcription. GPT-Live 1 uses GPT-5.6 Luna for in-depth answers. Live voice chat does not run local tools.

Get a Gemini API key

Free tier: Gemini TTS and Live currently have a rate-limited free tier. Submit your key in the Connections tab.

  1. Open and sign in with a Google account.
  2. Open the and check the free tier limits.
  3. In AI Studio → Get API key → Create API key — copy the key.
  4. Paste it in Connections → Voice Engine.
